First launch

Install in a minute.

Steps for your system, plus what to do if it warns about an “unknown developer”.

  1. Run JARVIS-windows-x64-setup.exe.
  2. If SmartScreen says “Windows protected your PC”, click More info, then Run anyway.
  3. Finish the wizard and open JARVIS from the Start menu.

The warning appears because the installer isn’t code-signed (certificates cost money and this is a free project). Checking the checksum below proves the file is the one that was published.

  1. Open the .dmg and drag JARVIS to Applications.
  2. Right-click JARVIS → Open → Open. (Or System Settings → Privacy & Security → Open Anyway.)
  3. Allow Microphone, Screen Recording, Accessibility and (optionally) Camera when asked.

Not sure which disk image? Apple silicon = M1, M2, M3 and newer. Intel = older Macs. Apple menu → About This Mac tells you.

  1. Install the libraries: sudo apt install libportaudio2 libxcb-cursor0 libxkbcommon-x11-0
  2. Extract the archive and run ./install.sh.
  3. Open JARVIS from your applications menu, or type jarvis.

Built on Ubuntu 22.04, so it runs on most current distributions.

Then paste your free Gemini API key on the setup screen and confirm your operating system (JARVIS detects it for you). See the first-launch guide.

Requirements

What you need.

A computer

Windows 10/11, macOS or 64-bit Linux. No GPU — the avatar renders in software.

Mic & speakers

Needed for voice. You can also type to JARVIS.

Internet & a free key

The conversation runs on Gemini Live, so you need a connection and a free API key from Google AI Studio.

Verify your download

Make sure it’s the real thing.

Every release includes SHA256SUMS.txt. Compare the checksum of your download with the published one.

Windows (PowerShell)

powershell
Get-FileHash .\JARVIS-windows-x64-setup.exe -Algorithm SHA256

macOS

terminal
shasum -a 256 JARVIS-macos-arm64.dmg

Linux

bash
sha256sum -c SHA256SUMS.txt --ignore-missing

The output must match the line for your file in SHA256SUMS.txt. If it doesn’t, don’t run the file — download it again from the releases page.
