What is Mark LIV?

Mark LIV is a real-time voice assistant that runs on your own computer. It hears you, sees your screen or webcam when you ask, answers out loud, and can act — opening apps, changing settings, searching the web, managing files and setting reminders. Conversation runs on Google’s Gemini Live API, so you need a free API key; everything else (memory, settings, accounts) stays on your machine.

Its window is called JARVIS: a HUD with an animated face (or a reactor-core display), a waveform, a log of the conversation and a settings drawer.

Quick start

  1. Download and install for your operating system (see Installation).
  2. Get a free key at Google AI Studio.
  3. Start JARVIS, paste the key, confirm your operating system, and press Continue.
  4. Hold Ctrl + Space (once push-to-talk is on) or simply talk, and say something like “What’s the weather today?”

Installation

  1. Download JARVIS-windows-x64-setup.exe from the download page.
  2. Run it. If Windows SmartScreen says “Windows protected your PC”, choose More info → Run anyway (the installer isn’t code-signed).
  3. Follow the wizard. JARVIS installs for your user account only — no administrator rights needed.
  4. Start it from the Start menu. Tick Start JARVIS when I sign in during setup if you want it always ready.

To remove it, use Settings → Apps. Your settings and memory are kept in the install folder; delete %LOCALAPPDATA%\Programs\JARVIS afterwards to erase them.

  1. Download the .dmg that matches your Mac: arm64 for Apple silicon (M1 or newer), x64 for Intel. Not sure? Apple menu → About This Mac.
  2. Open the disk image and drag JARVIS onto Applications.
  3. Open it from Applications. macOS will say it can’t verify the developer: right-click JARVIS → Open → Open, or go to System Settings → Privacy & Security → Open Anyway.
  4. Allow the permissions it asks for: Microphone (voice), Screen Recording (looking at your screen), Accessibility (controlling apps) and Camera (optional).
terminal
xattr -dr com.apple.quarantine /Applications/JARVIS.app

The command above is the terminal equivalent of “Open Anyway”. On first launch JARVIS copies itself to ~/Library/Application Support/JARVIS, which is where your settings and memory live — updates keep them.

  1. Install the two system libraries the app needs (Debian / Ubuntu shown):
bash
sudo apt install libportaudio2 libxcb-cursor0 libxkbcommon-x11-0
  1. Download JARVIS-linux-x64.tar.gz, then extract and install:
bash
tar -xzf JARVIS-linux-x64.tar.gz
cd JARVIS-linux-x64
./install.sh
  1. Open JARVIS from your applications menu, or run jarvis in a terminal.

It installs to ~/.local/share/jarvis and needs no root access. ./uninstall.sh removes it and keeps your settings.

Run from source

Prefer Python? Clone the project and let the setup script install exactly what your OS needs.

bash
git clone https://github.com/YOUR-USERNAME/Mark-LIV.git
cd Mark-LIV
python setup.py      # installs dependencies for YOUR operating system
python main.py

The source install also supports the optional “Hey Jarvis” wake word (pip install openwakeword, or one click from the settings drawer). The packaged installers leave the wake word out to keep the download small; push-to-talk works everywhere.

First launch

1. Add your Gemini API key

A setup screen asks for your key. Create one for free at aistudio.google.com/apikey and paste it in. It is saved on your computer in config/api_keys.json (plain text — treat the file like a password).

2. Confirm your operating system

The same screen shows three buttons — Windows, macOS, Linux. JARVIS detects your system and pre-selects it, and you can change it before continuing. This choice tells the assistant which native tools to use for volume, brightness, reminders and app launching.

3. Say hello

The HUD wakes up and greets you. Everything after this is a conversation.

Memory, undo & confirmations

Memory

JARVIS remembers your projects, preferences and context between sessions. Nothing is deleted automatically; the prompt carries a compact core and the rest is looked up on demand. Open ⚙ → MEMORY to see every stored fact and remove any of it. It all lives in memory/long_term.json — delete the file to make it forget everything.

Undo

Say “undo” in any language to reverse the last action: file move, rename, create, copy, write or delete, desktop organising, and volume, brightness or dark-mode changes. Files over 1 MB are excluded from write-undo, and where a setting can’t be read back beforehand, nothing is registered — it never guesses.

Confirmations

Shutdown, restart and WiFi changes show a banner on the HUD and run only if you press CONFIRM. The AI cannot confirm on your behalf.

Safety notes

JARVIS can act on your computer. That is the point, and it deserves care.

  • Keep config/api_keys.json private — it holds your API key in plain text.
  • Only pair phones and create dashboard accounts you trust; an account can drive your computer.
  • Sensitive actions (shutdown, restart, WiFi) always ask you first, but review what you ask it to do with files.
  • While a session is open your voice, and any image you ask it to look at, is streamed to Google’s Gemini API. Mute or close the app to stop. See privacy.

Pair your phone

The phone dashboard lets you chat with JARVIS, send it files and speak commands from any phone or tablet on the same Wi-Fi network.

  1. In the JARVIS window press Remote Control. It shows a QR code, a 6-character code and the address, for example https://192.168.1.20:8000.
  2. On your phone, scan the QR code — you are signed in automatically. Or open the address, choose Quick connect and type the code. Each code works once and expires after 10 minutes.
  3. The first time, your browser warns about the certificate. JARVIS creates its own self-signed certificate on your computer; choose Advanced → Continue. Traffic stays on your network.

Uploads from your phone land in Downloads/JARVIS Uploads (up to 500 MB per file). Commands from the dashboard are AES-256 encrypted.

Voice from a phone needs a secure page. Because the dashboard uses a self-signed certificate, Chrome on Android may need a one-time flag; the dashboard shows step-by-step instructions the first time you tap the microphone.

Accounts

Beyond one-time codes, the dashboard has proper Sign in and Create account pages so your phone can reconnect without scanning again.

  • Creating an account needs the device code shown under Remote Control. It proves you are at the computer — nobody else on your Wi-Fi can register themselves.
  • After that, sign in with your email and password. No code is needed again.
  • Passwords are stored as salted scrypt hashes in config/accounts.json on your computer. Failed attempts are rate-limited.
  • Use the avatar menu (top right of the dashboard) to Sign out, which also forgets that phone.

Google sign-in

Optional, free, about five minutes.

  1. In Google Cloud Console, create an OAuth client ID of type Web application (set up the consent screen first; while it is in Testing, add your own Google account as a test user).
  2. Under Authorized JavaScript origins add https://localhost:8000 and http://localhost:8000. No redirect URI is needed.
  3. Put the client ID in config/api_keys.json (or set the environment variable JARVIS_GOOGLE_CLIENT_ID) and restart JARVIS:
json
{
  "google_client_id": "1234567890-abc123.apps.googleusercontent.com"
}

Where it works. Google only allows sign-in from localhost or a real domain name — never from a bare address like 192.168.1.20. So the Google button works in the browser on your computer at https://localhost:8000. To use it from a phone, serve the dashboard under a domain (a Cloudflare or Tailscale tunnel, or your own domain pointing at the PC) and add that origin in step 2. On a plain LAN address the page says so and you can use email and password or the QR code.

A brand-new Google account still needs the device code once, exactly like an email account.

Write a plugin

A plugin is one Python file in the plugins folder. JARVIS discovers it at startup — nothing else to register. Files starting with an underscore are ignored, and a plugin that fails to load is skipped without affecting the rest.

python
PLUGIN = {
    "name": "coin_flip",                       # snake_case, unique
    "description": "Flip a coin when the user asks for heads or tails.",
    "parameters": {"type": "OBJECT", "properties": {}, "required": []},
}

def run(parameters: dict, player=None, session_memory=None) -> str:
    import random
    result = random.choice(["heads", "tails"])
    if player:
        player.write_log(f"JARVIS: {result}")
    return f"It's {result}."       # this text is spoken back to the user

The description is what the AI reads to decide when to call your plugin — be specific about trigger phrases. Return a short sentence; never raise an exception (return a spoken error instead). plugins/_template.py is a fuller starting point.

In the installed app, put plugins in the plugins folder inside the install location (see Configuration). Third-party libraries a plugin needs must already be bundled; the source install has no such limit.

Troubleshooting

JARVIS can’t hear me

Open ⚙ → AUDIO DEVICES and pick your microphone by name. On macOS check System Settings → Privacy & Security → Microphone; on Windows Settings → Privacy → Microphone.

Windows: “Windows protected your PC”

Choose More info → Run anyway. The installer isn’t code-signed. You can compare its SHA-256 checksum with SHA256SUMS.txt on the release page first (see Verify your download).

macOS: “cannot be opened because the developer cannot be verified”

Right-click the app → Open → Open, or System Settings → Privacy & Security → Open Anyway. Move it to Applications before the first launch.

Linux: it won’t start or has no sound

Install the libraries: sudo apt install libportaudio2 libxcb-cursor0 libxkbcommon-x11-0. Mouse and keyboard control work best in an X11 session; some desktop-control features are limited on Wayland.

My phone can’t connect

  • Phone and computer must be on the same Wi-Fi. “Guest” networks often block devices from each other.
  • Allow JARVIS through your firewall (inbound TCP port 8000).
  • Use the address shown in Remote Control, and accept the certificate warning once.
  • If port 8000 is taken by another program, close that program and restart JARVIS.

The Google button is greyed out or shows a message

Read Google sign-in — you need a client ID, and Google only works from localhost or a domain, not a LAN address.

Browser Control says a browser is missing

Installed builds: run JARVIS --install-browser once. From source: python -m playwright install chromium.

Start fresh

Delete config/api_keys.json to see the setup screen again, or memory/long_term.json to clear its memory.

Build & release

Maintainers: pushing a tag such as v1.0.1 makes GitHub Actions build the Windows installer, the two macOS disk images and the Linux archive, publish them with a SHA256SUMS.txt, and the website’s download buttons pick them up automatically. The full guide is packaging/README.md in the repository.

bash
git tag v1.0.1
git push origin v1.0.1
