Security & privacy

Built to be trusted with your computer.

An assistant that can act on your machine has to earn that access. Here is how Mark LIV does.

Local by default

Your API key, memory and dashboard accounts live in files on your own computer. There is no Mark LIV server, no telemetry and no sign-up to use the app.

You hold the keys

Irreversible actions ask for a confirmation the model cannot forge. Everything reversible is done at once — and can be undone.

A locked-down remote

Dashboard commands are AES-256 encrypted. New accounts need a one-time code shown on the computer, passwords are stored as salted scrypt hashes, and sign-in attempts are rate-limited.

Nothing hidden

Your memory panel shows everything it knows about you, and you can delete any of it. The source is open for you to read.

One honest thing. While a session is open, your voice — and any screen or camera image you ask it to look at — is streamed to Google’s Gemini API. Mute or close the app and it stops. See the privacy page for the full picture.

FAQ

Questions, answered.

Is it really free?
Yes. The app costs nothing and has no subscription. The only thing you need is a free Gemini API key from Google AI Studio (Google’s own free-tier limits apply). Mark LIV is licensed for personal, non-commercial use.
Does it need an internet connection?
Yes, for the assistant itself — conversation runs on the Gemini Live API. Your memory, settings and dashboard accounts are stored locally.
What gets sent to Google?
Your voice and text while a session is open, and a screen or camera image only when you ask it to look. Nothing is sent while you are muted or the app is closed. Details are on the privacy page.
Is it safe to let an AI control my computer?
It acts on your machine only, asks you to press a button for irreversible actions like shutdown, and can undo file moves and setting changes. It is still a powerful tool — read the safety notes before you start.
Which operating systems are supported?
Windows 10 and 11 (64-bit), macOS on Apple silicon and Intel, and 64-bit Linux (built on Ubuntu 22.04; most current distributions work).
Windows or macOS warns about an unknown developer. Why?
Installers are not code-signed — signing certificates cost money and this is a free project. The first-launch guide shows how to open the app, and you can verify the download with its SHA-256 checksum.
Can I use it commercially or sell it?
No. Mark LIV is licensed under Creative Commons Attribution-NonCommercial 4.0. Personal and non-commercial use, sharing and modification are welcome, with credit to the creator. See terms & license.
Can I add my own skills?
Yes. A plugin is one Python file dropped into the plugins folder. The plugin guide has a complete example.
